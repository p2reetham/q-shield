# Q-SHIELD API Reference

Base URL (dev): `http://localhost:8000`

| Method | Path                              | Description |
|--------|-----------------------------------|--------------|
| GET    | /api/health                       | Service health check |
| GET    | /api/keys                         | List signing keys |
| POST   | /api/keys/generate                | Generate an RSA-2048 key pair |
| POST   | /api/keys/{key_id}/rotate         | Revoke old key, generate a replacement |
| POST   | /api/keys/{key_id}/revoke         | Revoke a key |
| GET    | /api/keys/{key_id}/history        | Signature history for a key |
| POST   | /api/sign                         | Sign document content with a key |
| POST   | /api/verify                       | Verify a signature (by id, or by key+content+signature) |
| GET    | /api/signatures                   | List recent signatures |
| POST   | /api/threat/analyze               | Run the threat-scoring pipeline (rule+ML+quantum) |
| GET    | /api/threat/score/{score}         | Map a raw score to its NORMAL..CRITICAL band |
| POST   | /api/quantum/optimize             | Run the QUBO / simulated-annealing feature selector |
| GET    | /api/blockchain                   | List blockchain blocks |
| GET    | /api/blockchain/{block_id}        | Get one block |
| GET    | /api/blockchain/verify/chain      | Verify hash-chain integrity |
| GET    | /api/events                       | List security events (filterable) |
| GET    | /api/alerts                       | List alerts |
| POST   | /api/alerts/{alert_id}/acknowledge| Acknowledge an alert |
| POST   | /api/alerts/{alert_id}/resolve    | Resolve an alert |
| GET    | /api/dashboard/summary            | Aggregated dashboard stats |
| POST   | /api/demo/simulate-attack         | Run the full end-to-end demo pipeline |

Interactive docs are also auto-generated by FastAPI at `/docs` (Swagger UI) and
`/redoc` when the backend is running.
